# Gradient Studio

Генератор абстрактных градиентных фонов: мешевые градиенты, плавающие линии,
объёмные волны, шторки, зернистость и текстовые слои с перетаскиванием.

**Открыть:** https://bg.bestpracticeai.ru

Зеркало: https://isalin84.github.io/Backgrounds/

## Что умеет

- Мешевый градиент до 8 цветовых точек, смешивание через OKLab
- Поток и доменное искажение — то самое «плавание» линий
- Объёмные волновые ленты с воздушной перспективой
- Шторки: свой угол, шаг, скважность, мягкость, 4 режима наложения
- Зерно от нуля до плёночной крупы, дизеринг против полошения
- Сколько угодно текстовых слоёв, у каждого свой шрифт; перетаскивание с прилипанием
- Экспорт: PNG, JPEG, WebP, SVG, PDF, JSON, самодостаточный HTML, CSS-сниппет
- 14 пресетов, гармоничный рандомайзер, undo/redo, автосохранение

## Как устроено

Один файл `index.html` — без сборки и зависимостей, кроме `<link>` на Google Fonts.
Фон рисуется фрагментным шейдером на WebGL2, поэтому все параметры пересчитываются
в реальном времени.

Локально файл можно просто открыть двойным кликом. Если нужен автосейв в localStorage,
запустите любой статический сервер:

```
python3 -m http.server 8931
```

## Требования

Браузер с WebGL2 — Chrome, Safari 15+, Firefox, Edge.
